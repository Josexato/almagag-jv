# almagag-ts

Reescritura en TypeScript, para browser y Node, del motor de diagramas
[AlmaGag](https://github.com/Josexato/AlmaGag). Entrada: string JSON `.sdjf`/`.gag`.
Salida: string SVG.

- **Motor de referencia (oráculo congelado):** AlmaGag Python **v3.20.0**.
- **Estado:** previo a la fase 0. La propuesta está en [`docs/PROPUESTA-v0.md`](docs/PROPUESTA-v0.md).
- **Golden de referencia:** [`golden/REFERENCE-v3.20.0.md`](golden/REFERENCE-v3.20.0.md),
  generado con `golden/scripts/measure_reference.py <repo-AlmaGag>`.
